# 논문 인용과 버전 고정

저장소 주소: https://github.com/F4deout/iunex-synthetic-reproducibility

배포 태그: `v1.0.0`

인용 예시:

> IUNEX Synthetic Research Reproducibility Materials, v1.0.0, GitHub repository, https://github.com/F4deout/iunex-synthetic-reproducibility/tree/v1.0.0 (접근일은 실제 확인일 기입).

최종 논문에는 사용한 commit SHA를 함께 기록할 수 있습니다. `git rev-parse v1.0.0^{commit}`으로 태그가 가리키는 commit을 확인합니다. 태그의 내용을 사후 변경하지 않고 변경은 새 commit/새 버전으로 기록합니다.

코드 저장소의 소유 계정과 논문 저자는 동일하다고 가정하지 않습니다. 미확정 저자·연락처나 DOI를 임의로 만들지 않았습니다. 저장소가 비공개인 동안은 공개 재현자료라고 기술하지 않고, 심사자가 접근할 수 있는 별첨 제출 방식을 병행합니다.


## v1.1.0 추가 안내

최초 자료는 `v1.0.0`, 두 추가 핵심 실험은 `v1.1.0`을 사용합니다. 추가 자료 인용 시 `https://github.com/F4deout/iunex-synthetic-reproducibility/tree/v1.1.0`과 해당 commit SHA를 함께 기록합니다. 기존 v1.0.0 인용 예시와 태그는 역사적 기록으로 유지합니다.
