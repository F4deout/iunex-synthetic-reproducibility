# 관측시간 처리 수정 및 구간 민감도 보완 분석

기존 결과 확인 후 작성한 사후 방법론 개정. 생성기·parameter·history·기존 결과 및 원고는 변경하지 않는다. 새 결과 확인 전에 아래 분석을 고정한다.

## 문제와 수정

기존 logistic hazard는 실제 중단시간을 마지막 구간 끝점으로 학습하지만 예측은 공통 5분 격자를 사용한다. 서로 다른 마지막 구간의 노출시간도 보정하지 않는다.

구간별 지수위험모형(piecewise exponential model)으로 별도 수정한다. 이는 단순 코드 정리뿐 아니라 likelihood의 변경이다. 모든 사람에게 공통인 0–90분 격자를 정의하며 각 구간의 실제 관측 노출시간을 반영한다. 사건은 (왼쪽, 오른쪽]에 배정한다. 완료는 계획시간에서 우측 검열한다. 부분 관측 구간도 노출시간만큼 기여하고 미관측 구간은 학습하지 않는다.

log(rate/minute)=intercept + 기존 observed features + a*(공통구간끝/90) + b*log(1+공통구간끝)/log(91).
음의 로그우도=Σ[노출분×rate − 사건여부×log(rate)] + L2/(2C). 노출시간은 offset(log exposure)와 동등한 방식으로 처리한다. 구간 끝은 실제 정답시간으로 바꾸지 않는다. 시간함수는 기존 두 특징을 유지하며 비례위험 구조를 갖는 제한된 모형이다.

## 고정 비교

- seed110/220/330/440/550, 기존 subject split·동일 평가 세션.
- k=0/1/3/5/10/20, pooled/하중행군/순환운동, 구간1/2.5/5/10분 전체:360조건.
- 5분은 기존과의 비교 기준으로 유지하고 시험 결과로 최적 간격을 선택하지 않는다.
- 기존 train-only Prep, C=.1/1/10. validation의 세션당 정확한 검열우도로 선택. train+validation 최종적합에도 train에서 적합한 Prep 유지.
- endpoint: 계획시간까지 관측 중단확률; Brier 주지표, logloss/AUC 보조. RMST는0–90분 생존함수의 구간별 해석적 적분, C-index 보조. 중단사례만의 RMST MAE는 기술치이며 전체 대상의 시간 MAE로 해석하지 않는다.
- 각 seed·scope·k·간격별 결과와 raw prediction을 모두 보존. 5-seed 평균/SD/t(4)95%기술구간 및 k0 대비 paired 효과. 새 유의성 검정 없음.
- 기존 5분 모형 대비 결과와 방향을 대조하되 likelihood와 적분법도 바뀌었으므로 구간 크기만의 효과로 해석하지 않는다. 간격 민감도는 새 모형 내부에서 비교한다.

## 실행 전·후 검증

노출합=관측시간, 사건합=사건여부, 정확한 경계배정, 검열 부분구간, 학습/예측 동일격자, 상수위험 생존확률 및 RMST 해석해, 사건수/노출합 MLE, Newton 수렴, 분할 겹침0, 동일test세션, 잠재/현재결과 feature 누출 없음, 원본hash 불변 및 생성자료hash 기존과 동일 검증.

수치 최적화는 최대100회 Newton+backtracking, decrement/상대목적함수와 scaled gradient 검사를 사용한다. 수렴 실패는 숨기지 않고 분석 오류로 보고한다. 로그위험을 결과에 맞춰 clip하지 않는다.

한계: 기존5seed의 수정 평가이므로 독립 외부검증이 아니며, 시간구간 민감도나 수렴 PASS가 생성계수·의료적 타당성을 증명하지 않는다.
