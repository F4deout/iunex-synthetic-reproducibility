# RQ1 longitudinal v2 parameter amendment 01

## 1. 목적과 변경 범위

기존 `RQ1_LONGITUDINAL_V2_PROTOCOL.md`의 연구질문·분할·이력 비교·판정 규칙은 변경하지 않고, 구현 전 미확정이었던 자료 생성 변수의 출처와 값을 고정한다. 이 보정은 v1 결과를 보고 성능을 높이기 위한 조정이 아니며, v2 생성·예측 결과를 보기 전에 수행하였다.

## 2. 실제 자료에서 확인한 범위

PMData 16명에서 Fitbit 운동 2,440건, 일별 wellness 1,747건, session-RPE 772건을 확인하였다. 운동기록 2,427건에 평균 심박수가 존재하였다. 독립 5 km 기록은 15명에서 18.78–47.47분이었다.

이 자료는 군 장병 모집단 추정치가 아니라 **empirical calibration reference**로만 사용한다. 실제 자료로 직접 제약할 수 있는 항목은 관측 간격, 운동 지속시간, 운동별 평균 심박수, 일별 피로·준비도의 관측분포 및 session-RPE 분포이다. 다음은 직접 보정할 수 없다.

- 하중 이동의 진짜 수행능력·하중·경사 반응
- 맨몸 순환운동의 작업–휴식 반응과 과업별 수행능력
- 표준화된 운동 후 반복 측정한 빠른·느린 회복 시간상수
- 운동과 쌍을 이룬 체온·SpO₂·혈압·ECG·땀 젖산
- 장치별 측정오차, artifact 및 결측 분포
- 동일 과업의 반복 자기보고로 추정한 보고 오차와 재검사 신뢰도

## 3. 미해결 항목의 사전 고정

### 3.1 활동 구성

다과업 활동 비율을 군 모집단 유병률처럼 추정하지 않는다. v2 기본 실험은 활동 없음·유산소 운동·하중 이동·맨몸 순환운동을 각 25%로 배치하는 **controlled support design**으로 고정한다. 이 비율은 현실 부대의 활동 빈도가 아니라 각 정보 경로의 평가 지원을 확보하기 위한 방법 선택이다.

유산소 운동 지속시간은 PMData 러닝 기록의 25·50·75 백분위(29.56·4444.85·67.72분)를 경험적 지원점으로 고정한다. 외부 요구량은 독립 5 km 기록 기준속도에 대한 0.70·0.90·1.10배를 고정하되, 이 비율을 실제 CS 또는 군 표준 운동강도로 해석하지 않는다. 하중 이동과 맨몸 순환운동은 결과 생성 전에 동결된 v2.2 격자를 그대로 사용한다.

### 3.2 관측 간격과 회복

BASE 관측 간격은 PMData wellness 일자 간격의 고정 경험분포를 재표집한다. LOW/HIGH는 결과 민감도 확인을 위한 밀집·희소 관측 가정으로, LOW는 간격을 1–3일로 상한 제한하고 HIGH는 경험 간격의 3배(최대 45일)로 고정한다. 이는 기록 빈도이며 생리적 회복시간이 아니다.

빠른 회복 10·30·60분, 느린 회복 12·24·48시간은 기존 v2.3의 LOW/BASE/HIGH simulation assumption을 유지하고 전 조건을 보고한다. PMData 기록 간격을 회복 시간상수의 실측치로 재해석하지 않는다.

### 3.3 환경

v2-minimal은 환경을 중립 조건으로 고정한다. 기온·습도 반응은 현재 RQ1의 핵심 식별 대상이 아니고, PMData에 세션별 노출 환경이 없으므로 v2-extended로 유보한다. 중립 고정은 환경의 영향이 없다는 실증 주장이 아니라 현 실험의 범위 제한이다.

### 3.4 생리·측정 과정

안정 심박수 기준선은 이전에 동결한 v2 보정 P01 경험분포를 사용한다. 활동 반응, 개인차, 생리 변동 및 심박 측정오차는 v2.3의 LOW/BASE/HIGH를 그대로 유지한다. 체온·SpO₂ 측정오차와 artifact·결측은 `RQ1_STATE_MIXTURE_PARAMETERS.json`의 값을 **simulation assumption**으로 사용하며 장치 사양으로 표현하지 않는다. 땀 젖산은 쌍지은 실제 자료가 없으므로 v2-minimal 입력에서 제외한다.

### 3.5 정답 및 보고 과정

운동부담의 WEAK/BASE/STRONG, 피로·현재상태 결합계수, 점수 변환, 개인 보고편향 및 세션 오차는 v2.3의 동결값을 그대로 사용한다. 이 값은 PMData 신뢰도 추정치가 아니라 simulation assumption이다. 결과를 보고 이 개인차 크기와 label noise를 공동 조정하지 않고, 사전 고정한 전 민감도 조건을 보고한다.

## 4. 출처 분류

| 항목 | 분류 | v2-minimal 처리 |
|---|---|---|
| 기록 간격, 운동시간, 평균 HR, wellness/RPE 관측분포 | 실제 자료 보정 가능 | PMData 동결 artifact를 경험적 참조로 사용 |
| 5 km 기록 | 실제 자료 보정 가능 | 수행능력 anchor로만 사용; CS로 간주 금지 |
| 하중 이동·순환운동 지원 격자 | 문헌으로 범위 제한 | v2.2 격자 유지; 실제 군 검사 처방으로 해석 금지 |
| 수행능력 변화, 회복, 보고편향·오차, target coupling | simulation assumption | LOW/BASE/HIGH 전체 수행; critical |
| 체온·SpO₂ 측정오차·결측 | simulation assumption | 기존 state-mixture 값 사용; 장치 정확도 주장 금지 |
| 땀 젖산, 과업별 실제 수행능력, 군 모집단 분포 | UNKNOWN/NEEDS_SOURCE | v2-minimal에서 제외 또는 모집단 주장 금지 |

## 5. 실행 조건

최종 값은 `RQ1_LONGITUDINAL_V2_FINAL_PARAMETERS.json`에 저장하고 hash로 잠근다. 구현 후 생성분포·히스토리 성능·MAE를 보고 이 값을 변경하지 않는다. 구조적 오류가 발견되면 변수 튜닝이 아니라 별도 amendment와 재검증으로 처리한다.
