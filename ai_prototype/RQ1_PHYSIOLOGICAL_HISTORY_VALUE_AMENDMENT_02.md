# RQ1 생리·수행 이력 연구 사전등록 Amendment 02

작성일: 2026-10-08  
작성시점: Phase 1 코드 작성·결과 확인 전

## 변경 사유

잠긴 프로토콜은 여러 이력 길이를 비교하도록 정했으나 성공판정에 사용할 주 이력 길이를 지정하지 않았다. 결과 확인 후 유리한 길이를 선택하는 문제를 막고, 검열 중단시간 분석의 계산범위를 사전에 명확히 하기 위한 분석계획 보완이다.

## 주 비교

- 주 이력 길이: `k=20`
- 주 입력 비교: `C1 현재정보` 대 `C5 전체 객관적 이력`
- `k=0/5/10/20/30/50/75/100` 전체 결과는 증가·포화·악화 양상 분석으로 모두 보고
- 최저 오차를 보인 k를 사후 주 결과로 교체하지 않음

## 정보군 비교

- C1~C7의 연속 target과 완료 여부는 모든 k에서 평가
- C2·C3·C4는 각각 센서·수행·회복 이력의 추가 정보경로 분석
- C6·C7은 과거 자기보고가 포함된 보조 대조조건이며 생리적 개인화 성공판정에 사용하지 않음

## 검열 중단시간 분석범위

- log-normal AFT 주 비교: C1과 C5의 모든 k
- 정보경로 AFT: C2·C3·C4·C6·C7의 k=20
- 모든 조건에서 중단 session만을 이용한 관측 중단시간 Ridge 결과를 별도 제공
- AFT가 실행되지 않는 부차 조건은 누락으로 숨기지 않고 `NOT_IN_PREREGISTERED_AFT_SCOPE`로 표시

## 영향범위

- 생성식·parameter·자료분할·target·feature 변경 없음
- 기존 dry run과 동결 결과 변경 없음
- Phase 1 결과 확인 전 작성된 분석범위 명세
