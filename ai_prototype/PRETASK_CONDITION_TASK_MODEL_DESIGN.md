# 임무 전 개인 상태확인 및 예정 과업 결과예측 모형 설계안

## 1. 설계 목적

비착용형 공용 상태확인 스테이션에서 임무·훈련 전 측정한 생체정보와 개인의 이전 수행·회복기록을 이용하여 다음 정보를 제공하는 보조분석 모형의 설계

1. 측정 시점의 현재 상태 추정
2. 예정 과업 수행 시 예상 부담과 완료·중단 가능성 추정
3. 재측정 또는 의료진 확인이 필요한 상황의 구분

AI 결과는 질병 진단, 의학적 적합성 판정 또는 임무 수행 명령을 대신하지 않으며 의료인력과 지휘관의 판단을 지원하는 참고정보로 한정

## 2. 핵심 연구질문

### RQ1. 임무 전 현재 상태

임무 전 생체정보, 개인 기준선, 최근 활동·회복이력 및 환경정보가 임무 전 자기보고 피로·현재상태 또는 독립 평가정보의 예측에 추가 정보를 제공하는가?

### RQ2. 예정 과업의 결과

임무 전 정보와 예정 과업의 요구 수준을 결합하면 과업 완료 여부, 관측 중단시간, 수행 후 부담 및 회복지연을 예측할 수 있는가?

### RQ3. 개인화의 추가 가치

같은 임무 전 생체정보와 같은 예정 과업에서도 개인의 평소 기준선·수행능력·회복특성을 반영한 모형이 공통모형보다 추가 예측정보를 제공하는가?

## 3. 측정 시점과 자료 흐름

### 3.1 T0: 임무 전 측정

AI가 실제 추론에 사용할 수 있는 입력

- 심박수·체온·말초 산소포화도
- 선택적 상세 모듈의 혈압·심전도·R-R 간격
- 각 측정값의 시각·방식·품질·결측 여부
- 직전 활동의 종류·강도·지속시간·종료시각
- 마지막 휴식 이후 경과시간과 최근 반복 활동량
- 개인의 동일 조건 기준선 및 과거 반응·회복기록
- 현재 기상환경
- 예정 과업의 종류·강도·목표 지속시간·하중 등 외부 요구량

### 3.2 T1: 과업 중 기록

T0 예측의 입력으로 사용하지 않고 결과 정답과 사후 분석에만 사용

- 실제 시작·종료시각
- 완료·자발 중단·안전상 중단 여부와 사유
- 가능한 경우 수행속도·작업량·중간 심박 등 과업기록

### 3.3 T2: 과업 직후 측정

- 과업 후 생체정보
- 운동부담·피로·현재상태 자기보고
- 통증·불편감과 중단사유

### 3.4 T3: 회복 후 측정

- 사전 고정한 회복간격 이후 생체정보와 자기보고
- 기준선 복귀 정도
- 추가 휴식·진료 여부

T1~T3 자료는 다음 세션의 과거 이력으로는 사용할 수 있으나, 해당 세션의 T0 예측 입력으로는 사용할 수 없음.

## 4. 입력정보의 구분

### 4.1 현재 절대값

- T0 심박수·체온·SpO₂·선택적 혈압·ECG 관련 지표
- 측정값 자체와 품질정보를 분리하여 보존

### 4.2 개인 기준선 대비 변화

- 동일 측정상황에서 반복 관측한 개인 기준선과 T0 값의 차이
- 개인 내 표준화값과 최근 변화방향
- 전체집단 기준과 개인 기준을 함께 제시하고 어느 하나로 대체하지 않음

### 4.3 최근 회복상태

- 직전 과업 이후 경과시간
- 최근 누적 활동량과 과거 회복 소요시간
- 최근 생체정보가 기준선으로 복귀했는지 여부

### 4.4 예정 과업 요구량

- 유산소 운동: 속도·거리·목표시간
- 하중이 있는 이동: 이동속도·거리·하중·경사·목표시간
- 맨몸 순환운동: 동작·반복수·작업시간·휴식시간
- 기타 임무: 지속시간·신체부하 수준·환경노출 등 사전에 정의 가능한 요구조건

### 4.5 개인 능력 대비 상대 요구량

예정 과업의 절대 요구량을 개인의 독립 수행기록과 과거 완료·중단자료에 상대화한 특징

- 독립 수행기록은 공통 입력으로 제공
- 실제 잠재 수행능력이나 simulator 내부 parameter는 입력 금지
- 개인 이력이 부족한 신규 인원은 집단모형으로 처리

## 5. 예측대상

### 5.1 현재 상태 target

서로 다른 정답의 혼합을 방지하기 위해 개별 target으로 분리

- T0 자기보고 피로 0~10
- T0 자기보고 현재상태 0~10
- 필요 시 의료진의 재확인 판단 또는 별도 표준척도

자기보고 점수는 개인별 체감반응과 척도 사용방식이 함께 포함될 수 있으므로, 개인별 보고 기준과 생리상태 정보를 분리하는 반복측정 설계 필요

### 5.2 과업 결과 target

- 완료 여부
- 실제 관측 중단시간 또는 완료에 따른 우측 검열시간
- T2 운동부담·피로·현재상태
- T3 회복지연 또는 기준선 미복귀

### 5.3 안전 관련 endpoint

- 안전상 중단
- 의료진 확인
- 증상 발생

발생빈도가 낮고 임상적 의미가 다르므로 일반적인 완료·자발 중단과 별도 target으로 관리

## 6. 안전 규칙과 AI 예측의 분리

### 6.1 규칙 기반 안전층

- 생리적으로 위험할 수 있는 절대 측정값
- 신호 품질 부족 또는 필수값 누락
- 측정시각 불일치
- 즉시 의료진 확인이 필요한 증상

해당 조건에서는 AI 점수보다 안전 규칙을 우선하고 분석 보류·재측정·의료 확인으로 연결

### 6.2 학습형 예측층

안전 규칙을 통과한 입력에서 현재 상태와 예정 과업의 예상 부담·완료 가능성·중단시간을 추정

정상범위 안의 개인차는 개인 기준선과 예정 과업 요구량을 결합하여 해석하되, 위험 절대값을 개인 기준선으로 정상화하여 상쇄하지 않음.

## 7. 모형 구조

### 7.1 공통모형

개인 이력이 없거나 부족한 인원을 위한 집단 수준 예측모형

### 7.2 개인화모형

공통모형 입력에 다음 관측 이력 특징을 추가

- 안정 시 개인 기준선
- 과업 종류·강도별 생체반응 변화
- 실제 완료·중단과 수행시간
- 과업 후 부담·피로·현재상태
- 회복간격별 기준선 복귀 정도
- 개인 내 변동성과 시간에 따른 변화

### 7.3 Target별 독립 출력부

- 현재 피로·현재상태 회귀
- 과업 완료·중단 분류
- 관측 중단시간 survival/AFT 분석
- 수행 후 부담 회귀
- 회복지연 분류 또는 회귀

하나의 종합점수로 모든 결과를 합치지 않고 target별 결과와 불확실성을 별도 제시

### 7.4 기준모형

- 집단 평균 또는 빈도 baseline
- 현재 T0 정보만 사용하는 Ridge/logistic model
- 독립 수행기록만 추가한 모형
- 단순 개인 최근값·개인 평균
- T0 정보와 개인 이력을 결합한 Ridge
- 필요 시 사전 고정한 소규모 비선형 비교모형

개인화모형은 현재정보 모형뿐 아니라 단순 개인 평균도 넘어야 추가 AI 가치가 있다고 판정

## 8. 합성자료 생성구조

### 8.1 공통원인 구조

`개인 특성 + 임무 전 회복상태 + 최근 활동 + 환경 + 비관측 상태요인`

→ `T0 잠재 상태`

→ `T0 true physiology`

→ `T0 센서 관측값`

동시에

`T0 잠재 상태 + 개인별 체감 민감도 + 독립 보고과정`

→ `T0 자기보고 target`

그리고

`T0 잠재 상태 + 개인 수행능력 + 예정 과업 요구량 + 개인 지속능력·회복특성 + 비관측 요인`

→ `완료·중단시간 + T2 부담 + T3 회복결과`

관측 센서값으로 target을 직접 생성하지 않고 잠재상태를 공통원인으로 사용

### 8.2 개인별 체감반응

개인별 자기보고 차이를 단순 절편으로만 생성하지 않고 다음을 분리

- 동일한 잠재상태에 대한 개인별 체감 민감도
- 생체상태 변화에 대한 점수 반응 기울기
- 점수척도 사용방식에 따른 보고편향
- 세션별 독립 보고오차

체감 민감도와 보고편향은 독립 parameter family로 두고 결과에 맞춰 공동조정하지 않음.

### 8.3 시간구조

- 수행능력의 완만한 변화와 독립 변화사건
- 직전 과업에 따른 회복부채
- 개인별 회복속도
- 평가시점과 변화사건의 독립성

변화사건 flag와 T0·T1·T2·T3 시점을 audit record에 명시적으로 보존

## 9. 검증설계

### 9.1 자료분할

- subject-disjoint train/validation/test
- 같은 사람의 모든 세션을 하나의 split에 배치
- 과업 template가 존재하면 source-template group split 추가
- test는 최종 평가 전까지 모델 선택에 사용하지 않음

### 9.2 시간 누수 차단

- T0 예측에 현재 과업의 T1~T3 자료 입력 금지
- 현재 및 미래 자기보고 입력 금지
- 잠재 수행능력·잠재 회복상태 입력 금지
- 개인 이력은 T0보다 앞선 관측만 사용
- 전처리는 train에서만 적합

### 9.3 비교조건

- 개인 이력 없음
- 생체·활동 이력만
- 과거 자기보고만
- 수행·완료·중단 이력만
- 전체 이력

각 정보군 제거분석을 통해 예측이 어떤 과거 정보에 의존하는지 확인

### 9.4 평가단위

- 현재상태 점수: MAE·RMSE·R²
- 완료·중단: AUROC뿐 아니라 민감도·특이도·정밀도·calibration
- 관측 중단시간: MAE 및 검열이 존재하면 C-index·AFT 기반 평가
- 회복지연: 분류 또는 시간예측 지표
- 5개 이상 seed의 paired difference와 기술적 95% CI

합성 seed CI를 실제 사람 모집단의 신뢰구간으로 표현하지 않음.

## 10. 사전 반증시험

- target shuffle
- feature shuffle
- subject identity destruction
- history time-order destruction
- T1~T3 정보 차단 assertion
- 잠재정보 입력 차단 assertion
- 과거 자기보고 제거
- 과거 수행·중단정보 제거
- 개인별 체감 민감도 제거
- 보고편향 제거

## 11. 단계별 구현범위

### v1-minimal

- T0 HR·체온·SpO₂
- 개인 기준선·최근 활동·회복시간
- 예정 과업의 종류·강도·지속시간
- T0 피로·현재상태
- 완료 여부·관측 중단시간·T2 부담

### v1-extended

- 혈압·ECG·R-R 간격
- 기상노출
- T3 반복 회복측정
- 실제 중단사유와 우측 검열
- 부대·장비 간 외부검증

## 12. 현재 연구결과와의 관계

- 기존 활동 후 자기보고 예측결과는 보조 분석으로 보존
- 기존 관측 중단시간 결과는 과업 후 관측자료가 충분할 때 얻을 수 있는 정보가치의 합성 사례로 보존
- 새 모형의 주 입력은 T0 임무 전 정보로 제한
- 기존 결과를 새 임무 전 예측모형의 성능으로 재해석하지 않음

## 13. 구현 전 확정이 필요한 사항

1. T0·T2·T3의 정확한 측정 간격
2. 현재상태 자기보고 문항과 척도
3. 예정 과업 요구량의 공통 표현방법
4. 완료·자발 중단·안전상 중단의 기록기준
5. 개인 기준선에 필요한 최소 반복횟수
6. 임무 전 결과화면에서 표시할 예측값과 의료·지휘 판단의 경계
